# Playbooks — procedures earlier operators found that worked

One file per repeatable procedure (e.g. `grasp_5cm_cube.md`), written by a
previous session that got it to work here. A playbook is ADVICE, not a
contract: read it, then decide for yourself whether it fits the scene in front
of you. Structure each file as: Preconditions, Steps (with what to check after
each), Known failure modes and how the author recovered, Evidence (session +
frames). If your run contradicts a playbook, add a dated note at its bottom
rather than rewriting it.
