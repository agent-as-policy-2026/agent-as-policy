# playbook: clear-space canonical regrasp and staged collar insertion

<!-- from session 20260910_195248_paper_twopairs_full_high_kn_6astra_03, merged 2026-09-10 -->
1. Identify the demonstrated pairs and only the left set. Measure upright post centers, collar centers and heights; all x/y below are scene-dependent examples.
2. Check clearance for the camera housing as well as open fingers. If a tall neighbor obstructs a collar grasp, a yaw-90 external grasp can relocate the collar to clear table space. This run used quaternion (0,0.70710678,0.70710678,0), hex grasp z=-0.029, 130 mm lift, set-down at z=-0.026 and release. Example set-down x/y=(0.180,-0.030).
3. Lift clear, turn to quaternion (0,1,0,0), and measure the collar in that orientation. Canonical hex regrasp at example (0.182,-0.022,-0.029) gave width 52.6 mm. Close, inspect, lift 130 mm, inspect retention.
4. Measure the narrow post in the same orientation. This run measured approximately (0.271,-0.130), z=0.0331; use current measurements, not these coordinates.
5. Align above the post. Successful example grasp x/y=(0.269,-0.130). Descend through z=0.052, 0.020, -0.014 with images after each. Confirm the post through the hole before the last descent. Open, inspect, lift 150 mm and inspect stable seating.
6. Canonically grasp the round collar at its measured center. This run requested example (0.3465,-0.006,-0.028), achieved z=-0.03155, and obtained width 51.7 mm. Inspect closure, lift 140 mm and inspect retention.
7. Remeasure the wide post, especially if previously contacted. This run inserted at example grasp x/y=(0.292,0.125), using z=0.054, 0.021, -0.014. Inspect engagement at each stage, open, inspect settling, and lift 150 mm.
8. Return to observation posture with gripper open. Verify both assemblies remain stable and entirely in the left half in final overhead images. A SETTLE_MISS at the post top is failed alignment, not evidence of engagement: lift and re-perceive, and change grasp if repeated corrections fail.
